# PrintDesk 业务范围

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2

单企业、组织数据范围、按单生产的印刷/广告制作经营。报价、准确稿件版本的客户确认、派工、材料领退、工时/良品/报废、委外及分批收回、质检返工、分批交货、外部收款/原款退款、归档与订单成本。客户登录只看绑定客户的订单；生产账号只看本人派工且不读取售价/付款/利润。

金额采用十进制，数量/材料单位和币种显式。先实现可复核的成本加成报价，不承诺胶印拼版、机器排程、分色、印前内容检测。仓储存量由收发流水变化，客户实际确认不可由员工代替。修改商业报价或更新稿件须重新确认，不使用匿名共享密码。核心业务无需外部账号；支付、供应商、物流、邮件/短信及AI集成独立列为未实现。

DRAFT → QUOTED → ACCEPTED → IN_PROGRESS → READY → PART_DELIVERED → DELIVERED → CLOSED；客户拒绝报价进入CHANGES，可修订重报。最新稿件批准和报价批准后才可开工；质检不通过回到生产，保留原工时/报废/成本。每次变更要求版本和请求ID；重复相同请求不重复写入，结果未知时刷新核对。
